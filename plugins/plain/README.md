# Plain for Ghast

## 简介 / Overview

通过 Plain 官方账号 MCP 阅读客服线程、调查客户历史并管理帮助中心内容。

Read support threads, investigate customer history and manage help-center content through Plain’s official account MCP.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Plain OAuth 授权；受账号权限与服务配额限制。 已验证 S256 OAuth 跳转及必需的 openid offline_access 权限；未测试账号登录与客服操作。

Connect in Ghast and complete Plain OAuth in the provider browser page. Account permissions and service quotas apply. Verified S256 OAuth redirect with the required openid offline_access scopes. Account sign-in and support operations were not tested.

- MCP: `https://mcp.plain.com/mcp`
- [官方文档 / Provider documentation](https://www.plain.com/docs/agents/mcp-server)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
