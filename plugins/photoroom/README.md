# Photoroom for Ghast

## 简介 / Overview

通过 Photoroom 官方工具进行背景移除、虚拟模特展示等商品图创作与编辑。

Create and edit product visuals with Photoroom background removal, virtual models and other available official API tools.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Photoroom OAuth 授权；受账号权限与服务配额限制。 需要在 Photoroom Space 中启用 API，并使用具备所需 Space 管理员角色的账号。操作使用 Photoroom API 积分，而非普通 AI 积分。

Connect in Ghast and complete Photoroom OAuth in the provider browser page. Account permissions and service quotas apply. Requires a Photoroom Space with API access enabled and an account with the required Space admin role. Uses Photoroom API credits, not ordinary AI credits.

- MCP: `https://mcp.photoroom.com/mcp`
- [官方文档 / Provider documentation](https://help.photoroom.com/en/articles/15421163-photoroom-connector-for-claude-team-and-enterprise)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
