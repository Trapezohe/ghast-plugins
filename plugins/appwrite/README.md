# Appwrite for Ghast

## 简介 / Overview

通过 Appwrite 官方托管 MCP 管理云端项目、发现服务工具并搜索文档。

Manage Appwrite Cloud projects, discover service tools and search documentation through Appwrite’s official hosted MCP.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Appwrite OAuth 授权；受账号权限与服务配额限制。

Connect in Ghast and complete Appwrite OAuth in the provider browser page. Account permissions and service quotas apply.

- MCP: `https://mcp.appwrite.io/`
- [官方文档 / Provider documentation](https://appwrite.io/changelog/5)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
