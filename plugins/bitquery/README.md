# Bitquery for Ghast

## 简介 / Overview

通过 Bitquery 官方托管 MCP 研究链上成交、转账、代币市场与钱包活动。

Research on-chain trades, transfers, token markets and wallet activity through Bitquery’s official hosted MCP.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Bitquery OAuth 授权；受账号权限与服务配额限制。 通过浏览器 OAuth 连接 Bitquery 账号，受免费额度与付费套餐限制。托管数据集仅供读取，支持的链及历史范围以当前服务为准。

Connect in Ghast and complete Bitquery OAuth in the provider browser page. Account permissions and service quotas apply. Uses a Bitquery account through browser OAuth. Free-tier and paid-plan limits apply. The hosted dataset is read-only; supported chains and historical coverage depend on the current service.

- MCP: `https://mcp.bitquery.io/mcp`
- [官方文档 / Provider documentation](https://docs.bitquery.io/docs/mcp/mcp-server/)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
