# AgentMail for Ghast

## 简介 / Overview

通过 AgentMail 官方 MCP 管理智能体邮箱、邮件、会话、草稿与附件。

Manage agent email inboxes, messages, threads, drafts and attachments through AgentMail’s official MCP.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 AgentMail OAuth 授权；受账号权限与服务配额限制。

Connect in Ghast and complete AgentMail OAuth in the provider browser page. Account permissions and service quotas apply.

- MCP: `https://mcp.agentmail.to/mcp`
- [官方文档 / Provider documentation](https://www.agentmail.to/docs/integrations/mcp)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商官方 MCP 服务与软件包，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using official provider MCP services and packages, without Codex private connectors or credentials.
