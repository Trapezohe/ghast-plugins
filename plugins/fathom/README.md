# Fathom for Ghast

## 简介 / Overview

通过 Fathom 搜索会议记录、读取转录与摘要，整理决策和行动项。

Search meeting records, read transcripts and summaries, and extract decisions and action items through Fathom.


搜索会议记录、读取转录与摘要，整理决策和行动项。通过 Fathom 官方服务连接账号。

## 连接

在 Ghast 插件详情页点击「连接」，在服务提供方页面登录并授权。账号权限、套餐和组织策略以提供方为准。

- MCP endpoint: `https://api.fathom.ai/mcp`
- 上游文档: https://developers.fathom.ai/mcp-docs
- 本包由 Ghast 独立编写，使用供应商公开 MCP；不包含 Codex 插件、私有连接器 ID 或账号凭据。
- 安装提供 MCP 配置与任务技能，不代表已登录。真实账号授权与业务调用需在连接后验证。
- 断开连接清除 Ghast 保存的授权；如需撤销提供方授权，请到其账号设置操作。
