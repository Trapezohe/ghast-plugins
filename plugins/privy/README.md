# Privy for Ghast

## 简介 / Overview

检索 Privy 官方文档，获取嵌入式钱包、身份认证、签名策略与服务端集成指南。

Search Privy’s official documentation for embedded wallets, authentication, signing policies and server integrations.

## 连接 / Connection

公开 MCP 服务，无需账号或 API Key。 这是官方文档服务，不是 Privy 账号连接器。已发现全部 3 个工具并实际完成文档搜索。

Public MCP service; no account or API key required. This is the official documentation service, not a Privy account connector. All 3 tools were discovered and a documentation search returned results.

- MCP: `https://docs.privy.io/mcp`
- [官方文档 / Provider documentation](https://docs.privy.io/basics/get-started/using-llms)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
