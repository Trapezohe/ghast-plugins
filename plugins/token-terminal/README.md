## 简介 / Overview

使用 Token Terminal 研究链上项目、财务指标与统计方法。

Research onchain projects, financial metrics and methodologies with Token Terminal.

在 Ghast 中连接，通过服务商网页完成 Token Terminal OAuth 授权；受账号权限与服务配额限制。

Connect in Ghast and complete Token Terminal OAuth in the provider browser page. Account permissions and service quotas apply.

- MCP: `https://mcp.tokenterminal.com/mcp`
- [官方文档 / Provider documentation](https://tokenterminal.com/docs/mcp/introduction)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.
