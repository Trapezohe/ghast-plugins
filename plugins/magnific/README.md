# Magnific (Freepik) for Ghast

## 简介 / Overview

通过 Magnific（原 Freepik）官方 MCP 生成与编辑创意素材、浏览已有作品，并查看积分余额。

Generate and transform creative assets, browse previous creations and check credits through the official Magnific MCP, formerly Freepik.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Magnific (Freepik) OAuth 授权；受账号权限与服务配额限制。 需要 Magnific 付费套餐。生成或编辑内容消耗积分；查看余额与浏览已有作品不消耗积分。

Connect in Ghast and complete Magnific (Freepik) OAuth in the provider browser page. Account permissions and service quotas apply. Requires a paid Magnific plan. Generating or transforming content consumes credits; checking the balance and browsing past creations does not.

- MCP: `https://mcp.magnific.com`
- [官方文档 / Provider documentation](https://www.magnific.com/ai/docs/magnific-mcp)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
