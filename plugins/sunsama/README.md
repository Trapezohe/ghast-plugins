# Sunsama for Ghast

## 简介 / Overview

通过 Sunsama 官方 OAuth MCP 规划每日工作，管理任务、笔记和频道。

Plan daily work and manage Sunsama tasks, notes and channels through the official OAuth MCP connection.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Sunsama OAuth 授权；受账号权限与服务配额限制。 任务变更可能触发 Sunsama 自动化，并同步到已关联的任务服务。

Connect in Ghast and complete Sunsama OAuth in the provider browser page. Account permissions and service quotas apply. Task changes can run Sunsama automations and synchronize with linked task services.

- MCP: `https://api.sunsama.com/mcp`
- [官方文档 / Provider documentation](https://help.sunsama.com/docs/integrations/mcp/)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
