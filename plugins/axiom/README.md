# Axiom for Ghast

## 简介 / Overview

查询 Axiom 日志与事件，分析故障和运行趋势。

Investigate logs and events with Axiom dataset queries.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Axiom OAuth 授权；受账号权限与服务配额限制。 MCP 查询路由使用美国基础设施，请核对组织的数据驻留要求。

Connect in Ghast and complete Axiom OAuth in the provider browser page. Account permissions and service quotas apply. MCP query routing uses US infrastructure; check organization data residency requirements.

- MCP: `https://mcp.axiom.co/mcp`
- [官方文档 / Provider documentation](https://axiom.co/docs/console/intelligence/mcp-server)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
