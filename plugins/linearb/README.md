# LinearB for Ghast

## 简介 / Overview

通过 LinearB 官方 MCP 分析研发交付指标、仓库活动与 AI 采用情况。

Explore engineering delivery metrics, repository activity and AI adoption with LinearB’s official MCP.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 LinearB OAuth 授权；受账号权限与服务配额限制。 当前官方连接方式为管理员 OAuth，已取代旧版设置文档中的 Token 流程。

Connect in Ghast and complete LinearB OAuth in the provider browser page. Account permissions and service quotas apply. Administrator OAuth is the current official connection flow, superseding the token flow in the older setup article.

- MCP: `https://mcp.linearb.io/mcp`
- [官方文档 / Provider documentation](https://linearb.zendesk.com/hc/en-us/articles/45552138846491-2026-Release-Notes)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
