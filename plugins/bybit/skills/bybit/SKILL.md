# Bybit

Use ToolSearch to discover this plugin's connected MCP tools and read their actual schemas. Do not invent tool names or assume tools from another client exist. If disconnected, direct the user to Ghast plugin connection settings; never request secrets in chat.

Requires Node.js 20.6 or later. Use the bybit-public connection for market data without credentials; the bybit account connection requires both credential fields. For authorized account operations, enter a system-generated Bybit API Key and its HMAC API Secret in Ghast’s separate credential fields. This package uses mainnet and HMAC signing; it does not import RSA private keys. Bybit account permissions and region restrictions apply. The upstream package checks its release version at startup; a newer upstream release may require a plugin update. Local package initialization and tool discovery passed. Public and fixture-authenticated requests from the validation environment returned HTTP 403 because Bybit blocks its location. Live data retrieval, credential validity and account operations were not verified; installation is not proof of regional service availability.

Use bybit-public for public data and the credentialed bybit connection for account operations. Inspect live tool schemas before calling them. Both target mainnet, so distinguish public data from account actions. Resolve market category, symbol, order side, quantity, price and account before a requested order; never infer authority to trade from installation or a request for analysis. Orders, cancellations, transfers, withdrawals, borrowing and leverage or collateral changes require explicit user authorization. On an ambiguous transaction response, reconcile status before retrying to avoid duplicates. Respect region restrictions and API permissions. Never ask for private keys or secrets in chat.
