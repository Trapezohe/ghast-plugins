# Sanity for Ghast

## 简介 / Overview

检索结构化内容，管理 Sanity 文档与内容发布。

Query structured content and manage Sanity documents and releases.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Sanity OAuth 授权；受账号权限与服务配额限制。

Connect in Ghast and complete Sanity OAuth in the provider browser page. Account permissions and service quotas apply.

- MCP: `https://mcp.sanity.io`
- [官方文档 / Provider documentation](https://www.sanity.io/docs/ai/mcp-server)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
