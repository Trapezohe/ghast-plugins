# Eraser for Ghast

## 简介 / Overview

在 Eraser 中创建与编辑技术图表、搜索工作区文件并管理图表预设。

Create and edit technical diagrams, search workspace files and manage diagram presets in Eraser.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Eraser OAuth 授权；受账号权限与服务配额限制。 OAuth 请求消耗登录用户的 AI 额度，并归属于该用户。

Connect in Ghast and complete Eraser OAuth in the provider browser page. Account permissions and service quotas apply. OAuth requests use the signed-in user’s AI credits and are attributed to that user.

- MCP: `https://app.eraser.io/api/mcp`
- [官方文档 / Provider documentation](https://docs.eraser.io/mcp)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
