Search Crossmint’s official documentation for wallets, payments, minting and agent commerce integrations.

## 连接 / Connection

公开 MCP 服务，无需账号或 API Key。 这是官方文档服务，不是 Crossmint 账号连接器。已发现全部 3 个工具并实际完成文档搜索。

Public MCP service; no account or API key required. This is the official documentation service, not a Crossmint account connector. All 3 tools were discovered and a documentation search returned results.

- MCP: `https://docs.crossmint.com/mcp`
- [官方文档 / Provider documentation](https://docs.crossmint.com/introduction/ai-assistants)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.
