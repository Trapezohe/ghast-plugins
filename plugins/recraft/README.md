# Recraft for Ghast

## 简介 / Overview

通过 Recraft 生成和编辑位图或矢量图、移除背景并创建自定义风格。

Generate and edit raster or vector images, remove backgrounds and create custom styles with Recraft.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Recraft OAuth 授权；受账号权限与服务配额限制。 远程 MCP 使用 Recraft OAuth，图像操作受账号权限和可用额度限制。

Connect in Ghast and complete Recraft OAuth in the provider browser page. Account permissions and service quotas apply. The remote MCP uses Recraft OAuth. Image operations are subject to account permissions and available credits.

- MCP: `https://mcp.recraft.ai/mcp`
- [官方文档 / Provider documentation](https://www.recraft.ai/docs/mcp-reference/remote-server)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
