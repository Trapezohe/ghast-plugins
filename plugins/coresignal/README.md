# Coresignal for Ghast

## 简介 / Overview

通过 Coresignal 研究企业、员工与招聘岗位数据。

Research company, employee and job data with Coresignal.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Coresignal OAuth 授权；受账号权限与服务配额限制。 需要有效套餐或试用积分，并在 Coresignal 控制台配置团队 API Key；OAuth 会自动关联该密钥。

Connect in Ghast and complete Coresignal OAuth in the provider browser page. Account permissions and service quotas apply. Requires an active plan or trial with credits and a team API key provisioned in the Coresignal dashboard. OAuth resolves that key automatically.

- MCP: `https://mcp.coresignal.com/mcp/v2`
- [官方文档 / Provider documentation](https://github.com/Coresignal-com/coresignal-mcp)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
