# LiveKit Docs for Ghast

## 简介 / Overview

查询 LiveKit 官方文档、SDK 代码及更新日志，辅助开发实时音视频和语音智能体。

Search official LiveKit documentation, SDK code and changelogs to build real-time audio, video and voice agents.

## 连接 / Connection

公开 MCP 服务，无需账号或 API Key。

Public MCP service; no account or API key required.

- MCP: `https://docs.livekit.io/mcp`
- [官方文档 / Provider documentation](https://docs.livekit.io/reference/developer-tools/docs-mcp/)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.
