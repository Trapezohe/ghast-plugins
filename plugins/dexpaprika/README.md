# DexPaprika for Ghast

## 简介 / Overview

分析 DEX 流动性池、代币价格与历史链上行情。

Analyze DEX liquidity pools, token prices and historical on-chain market data.

## 连接 / Connection

公开 MCP 服务，无需账号或 API Key。

Public MCP service; no account or API key required.

- MCP: `https://mcp.dexpaprika.com/streamable-http`
- [官方文档 / Provider documentation](https://github.com/coinpaprika/dexpaprika-mcp)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.
