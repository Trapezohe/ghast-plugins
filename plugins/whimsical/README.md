# Whimsical for Ghast

## 简介 / Overview

搜索 Whimsical 文件，创建或编辑图表、线框图与可视化计划。

Search Whimsical files and create or edit diagrams, wireframes and visual plans.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Whimsical OAuth 授权；受账号权限与服务配额限制。 使用服务商托管的远程 MCP，无需运行 Whimsical 桌面应用；访问范围遵循工作区权限。

Connect in Ghast and complete Whimsical OAuth in the provider browser page. Account permissions and service quotas apply. Uses the provider hosted remote MCP; the Whimsical desktop app is not required. Access follows your workspace permissions.

- MCP: `https://mcp.whimsical.com/mcp`
- [官方文档 / Provider documentation](https://whimsical.com/learn/integrations/mcp)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
