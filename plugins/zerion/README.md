# Zerion for Ghast

## 简介 / Overview

检索 Zerion 官方 API 文档，了解钱包分析、投资组合接口、身份验证与集成方式。

Search Zerion’s official API documentation for wallet analytics, portfolio endpoints, authentication and integration guidance.

## 连接 / Connection

公开 MCP 服务，无需账号或 API Key。 本插件仅连接官方托管文档 MCP，不安装独立 Zerion CLI 及其钱包或交易功能。

Public MCP service; no account or API key required. This plugin connects only the official hosted documentation MCP. The separate Zerion CLI and its wallet or trading features are not installed.

- MCP: `https://developers.zerion.io/mcp`
- [官方文档 / Provider documentation](https://github.com/zeriontech/zerion-ai)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
