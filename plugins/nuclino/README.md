# Nuclino for Ghast

## 简介 / Overview

搜索 Nuclino 工作区、阅读页面并整理协作文档。

Search Nuclino workspaces, read pages and organize collaborative documentation.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Nuclino OAuth 授权；受账号权限与服务配额限制。 所有套餐的团队成员均可使用，访问范围遵循授权用户的权限。

Connect in Ghast and complete Nuclino OAuth in the provider browser page. Account permissions and service quotas apply. Available to all team members on all plans; access follows the authorizing user permissions.

- MCP: `https://api.nuclino.com/mcp`
- [官方文档 / Provider documentation](https://help.nuclino.com/70af7f4f-connect-nuclino-to-ai-assistants-with-mcp)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
