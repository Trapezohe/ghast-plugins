# Avaza for Ghast

## 简介 / Overview

管理项目、任务、工时、费用、发票与团队排期。

Manage projects, tasks, timesheets, expenses, invoices and team schedules.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Avaza OAuth 授权；受账号权限与服务配额限制。 需要 Avaza 付费套餐。

Connect in Ghast and complete Avaza OAuth in the provider browser page. Account permissions and service quotas apply. A paid Avaza plan is required.

- MCP: `https://mcp.avaza.com/mcp`
- [官方文档 / Provider documentation](https://support.avaza.com/avaza-mcp-server/)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
