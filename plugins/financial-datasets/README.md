# Financial Datasets for Ghast

## 简介 / Overview

通过 Financial Datasets 检索股票行情、公司财报、SEC 文件与新闻。

Research stock prices, company financials, SEC filings and news through Financial Datasets.


检索股票行情、公司财报、SEC 文件与新闻。通过 Financial Datasets 官方服务授权。

## 连接

在 Ghast 插件详情页点击「连接」，在服务提供方页面登录并授权。账号权限、套餐和组织策略以提供方为准。

- MCP endpoint: `https://mcp.financialdatasets.ai/`
- 上游文档: https://docs.financialdatasets.ai/mcp-server
- 本包由 Ghast 独立编写，使用供应商公开 MCP；不包含 Codex 插件、私有连接器 ID 或账号凭据。
- 安装提供 MCP 配置与任务技能，不代表已登录。真实账号授权与业务调用需在连接后验证。
- 断开连接清除 Ghast 保存的授权；如需撤销提供方授权，请到其账号设置操作。
