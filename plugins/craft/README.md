# Craft for Ghast

## 简介 / Overview

搜索与整理 Craft 文档、编辑内容，并管理已连接空间中的集合。

Search and organize Craft documents, edit content and manage collections in a connected space.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Craft OAuth 授权；受账号权限与服务配额限制。 在 Craft 授权页面选择目标空间，访问范围限定于所选空间。

Connect in Ghast and complete Craft OAuth in the provider browser page. Account permissions and service quotas apply. Select the intended Craft space on the provider authorization page. Access is scoped to that selected space.

- MCP: `https://mcp.craft.do/my/mcp`
- [官方文档 / Provider documentation](https://www.craft.do/imagine/guide/mcp/vscode)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
