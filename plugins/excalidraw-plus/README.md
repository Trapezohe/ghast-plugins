# Excalidraw+ for Ghast

## 简介 / Overview

在 Excalidraw Plus 工作区创建与编辑图表、线框图和演示画布，辅助创意表达。

Create and edit diagrams, wireframes and presentation scenes in an Excalidraw Plus workspace.

## 连接 / Connection

需要 Excalidraw Plus 账号与 API Key，在 Ghast 连接设置填写。供应商 API 与 MCP 处于公开测试阶段。

An Excalidraw Plus account and API key are required. Enter the key in Ghast connection settings. The provider API and MCP are in public beta.

- MCP endpoint: `https://api.excalidraw.com/api/v1/mcp`
- [Provider documentation / 官方文档](https://plus.excalidraw.com/docs/mcp)
- 安装后在 Ghast 插件详情连接服务；安装成功不代表账号授权或业务调用成功。
- Install in the Ghast plugin store, then connect in the detail page. Installation does not prove account authorization or task execution.
- 本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 插件、私有连接器 ID 或账号凭据。
- Independently authored for Ghast using the provider's public MCP service. No Codex packages, private connector IDs or credentials are included.
- 如需撤销授权，请同时检查服务商账号的授权设置。To revoke provider access, also review connected applications in your provider account.
