# Productboard for Ghast

## 简介 / Overview

在 Productboard 中搜索与完善产品规格、阅读反馈并跟踪交付状态。

Search and refine product specifications, read feedback and track delivery status in Productboard.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Productboard OAuth 授权；受账号权限与服务配额限制。 服务当前为 Beta。工作区管理员需要在设置 > MCP Server 中启用 MCP，并允许你的角色连接。

Connect in Ghast and complete Productboard OAuth in the provider browser page. Account permissions and service quotas apply. The service is Beta. A workspace admin must enable MCP under Settings > MCP Server and allow your role to connect.

- MCP: `https://mcp.productboard.com`
- [官方文档 / Provider documentation](https://developer.productboard.com/reference/mcp-install)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
