# lemlist for Ghast

## 简介 / Overview

通过 lemlist 官方 MCP 管理触达活动、查找销售线索并分析效果。

Manage outreach campaigns, explore leads and analyze performance with lemlist’s official MCP.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 lemlist OAuth 授权；受账号权限与服务配额限制。

Connect in Ghast and complete lemlist OAuth in the provider browser page. Account permissions and service quotas apply.

- MCP: `https://app.lemlist.com/mcp`
- [官方文档 / Provider documentation](https://help.lemlist.com/en/articles/13728466-set-up-the-lemlist-mcp-server-in-your-llm-client-oauth-or-api-key)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
