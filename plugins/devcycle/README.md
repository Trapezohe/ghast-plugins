# DevCycle for Ghast

## 简介 / Overview

查看和管理功能开关、定向规则与发布环境。

Inspect and manage feature flags, targeting rules and release environments.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 DevCycle OAuth 授权；受账号权限与服务配额限制。

Connect in Ghast and complete DevCycle OAuth in the provider browser page. Account permissions and service quotas apply.

- MCP: `https://mcp.devcycle.com/mcp`
- [官方文档 / Provider documentation](https://docs.devcycle.com/cli-mcp/mcp-getting-started/)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
