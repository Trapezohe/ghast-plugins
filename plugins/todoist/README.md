# Todoist for Ghast

## 简介 / Overview

规划项目、整理待办、查看截止日期与更新任务，通过 Todoist 连接账号。

Plan projects, organize tasks, review deadlines and update your to-do lists through Todoist.


规划项目、整理待办、查看截止日期与更新任务。通过 Todoist 官方服务连接你的账号。

## 连接

在 Ghast 插件详情页点击「连接」，在服务提供方页面登录并授权。账号权限、套餐和组织策略以提供方为准。

- MCP endpoint: `https://ai.todoist.net/mcp`
- 上游文档: https://developer.todoist.com/api/v1/#tag/Todoist-MCP
- 本包由 Ghast 独立编写，使用供应商公开 MCP；不包含 Codex 插件、私有连接器 ID 或账号凭据。
- 安装提供 MCP 配置与任务技能，不代表已登录。真实账号授权与业务调用需在连接后验证。
- 断开连接清除 Ghast 保存的授权；如需撤销提供方授权，请到其账号设置操作。
