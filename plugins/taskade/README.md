# Taskade for Ghast

## 简介 / Overview

通过 Taskade 官方托管 MCP 处理项目、任务、智能体与 Genesis 应用文件。

Work with Taskade projects, tasks, agents and Genesis app files through the official hosted MCP server.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Taskade OAuth 授权；受账号权限与服务配额限制。 托管 MCP 需要 Taskade 付费套餐。官方本地包是另一种连接方式，其工具集合不同，本插件不包含该本地包。

Connect in Ghast and complete Taskade OAuth in the provider browser page. Account permissions and service quotas apply. The hosted MCP requires a paid Taskade plan. The official local package is a separate connection option with a different tool catalog and is not bundled here.

- MCP: `https://www.taskade.com/mcp`
- [官方文档 / Provider documentation](https://www.taskade.com/learn/connect/mcp-server)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
