# Shortcut for Ghast

## 简介 / Overview

查找与管理 Shortcut 故事、史诗与文档，连接产品规划和研发工作。

Find and manage Shortcut stories, epics and documents to connect product planning with development.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Shortcut OAuth 授权；受账号权限与服务配额限制。

Connect in Ghast and complete Shortcut OAuth in the provider browser page. Account permissions and service quotas apply.

- MCP: `https://mcp.shortcut.com/mcp`
- [官方文档 / Provider documentation](https://www.shortcut.com/help/integrations/mcp-server/)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
