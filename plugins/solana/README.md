# Solana for Ghast

## 简介 / Overview

通过 Solana 官方开发者 MCP 检索生态文档，并检查 Anchor 或 Pinocchio Rust 程序。

Use Solana’s official Developer MCP to search ecosystem documentation and check Anchor or Pinocchio Rust programs.

## 连接 / Connection

公开 MCP 服务，无需账号或 API Key。

Public MCP service; no account or API key required.

- MCP: `https://mcp.solana.com/mcp`
- [官方文档 / Provider documentation](https://mcp.solana.com/)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
