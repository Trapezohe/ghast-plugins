# beehiiv for Ghast

## 简介 / Overview

通过 beehiiv 官方 MCP 管理通讯草稿、订阅受众、分群与增长分析。

Manage newsletter drafts, audiences, segments and growth analytics through beehiiv’s official MCP.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 beehiiv OAuth 授权；受账号权限与服务配额限制。 免费套餐仅支持读取，写入需要付费套餐；发布或定时发送通讯、激活自动化须在 beehiiv 应用中完成。

Connect in Ghast and complete beehiiv OAuth in the provider browser page. Account permissions and service quotas apply. Free plans are read-only; writes require a paid plan. Publish or schedule posts and activate automations in beehiiv itself.

- MCP: `https://mcp.beehiiv.com/mcp`
- [官方文档 / Provider documentation](https://beehiivhelp.zendesk.com/hc/en-us/articles/39255979546263-Getting-started-with-the-beehiiv-MCP)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
