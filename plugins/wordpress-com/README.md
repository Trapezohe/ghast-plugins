# WordPress.com for Ghast

## 简介 / Overview

通过 WordPress.com 官方 MCP 探索站点、文章、页面与内容发布工作流。

Explore WordPress.com sites, posts, pages and publishing workflows through its official MCP.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 WordPress.com OAuth 授权；受账号权限与服务配额限制。 请在 WordPress.com 账号设置中启用 MCP。付费套餐支持使用，免费站点仅在创建后的前 30 天支持 MCP。写入工具默认关闭，需要时由账号所有者启用。

Connect in Ghast and complete WordPress.com OAuth in the provider browser page. Account permissions and service quotas apply. Enable MCP in your WordPress.com account settings. Paid plans are supported; free sites have MCP access during their first 30 days. Write tools are disabled by default and must be enabled by the account owner when needed.

- MCP: `https://public-api.wordpress.com/wpcom/v2/mcp/v1`
- [官方文档 / Provider documentation](https://developer.wordpress.com/docs/mcp/)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商官方 MCP 服务与软件包，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using official provider MCP services and packages, without Codex private connectors or credentials.
