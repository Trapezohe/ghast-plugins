## 简介 / Overview

查询加密资产价格、历史走势、市场数据与交易池；公共服务无需 API Key。

Explore crypto prices, historical charts, market data and DEX pools. No API key required for the public service.

## 连接

无需账号授权；公共服务仍有频率限制。

- MCP endpoint: `https://mcp.api.coingecko.com/mcp`
- 上游文档: https://mcp.api.coingecko.com/
- 本包由 Ghast 独立编写，使用供应商公开 MCP；不包含 Codex 插件、私有连接器 ID 或账号凭据。
- 安装提供 MCP 配置与任务技能，不代表已登录。真实账号授权与业务调用需在连接后验证。
- 断开连接清除 Ghast 保存的授权；如需撤销提供方授权，请到其账号设置操作。
