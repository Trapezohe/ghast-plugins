# Relume for Ghast

## 简介 / Overview

查找 Relume 组件库内容，获取可编辑的 React 代码及其设计系统。

Find Relume library components and retrieve editable React code with its design system.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Relume OAuth 授权；受账号权限与服务配额限制。 使用 Relume 账号登录，组件访问受套餐限制。组件库使用 React、Tailwind 预设与共享基础组件，加入现有项目前应检查兼容性。

Connect in Ghast and complete Relume OAuth in the provider browser page. Account permissions and service quotas apply. Sign in with a Relume account. Component access follows your plan. The library uses React, Tailwind presets and shared primitives; check compatibility before adding it to an existing project.

- MCP: `https://relume-library-mcp.relume.io/mcp`
- [官方文档 / Provider documentation](https://www.relume.ai/relume-library-mcp)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
