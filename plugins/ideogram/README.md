# Ideogram for Ghast

## 简介 / Overview

在 Ideogram 中生成与编辑图像、整理创意素材并管理自定义模型工作流。

Generate and edit images, organize creative assets and manage custom-model workflows in Ideogram.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Ideogram OAuth 授权；受账号权限与服务配额限制。 MCP 使用量消耗与 Ideogram 网页应用相同的订阅额度。

Connect in Ghast and complete Ideogram OAuth in the provider browser page. Account permissions and service quotas apply. MCP usage draws from the same subscription credits as the Ideogram web app.

- MCP: `https://mcp.ideogram.ai/mcp`
- [官方文档 / Provider documentation](https://ideogram.ai/features/mcp/)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
