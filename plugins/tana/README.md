# Tana for Ghast

## 简介 / Overview

搜索 Tana 内容、读取会议上下文，并准备文档与结构化条目的更新。

Search Tana content, read meeting context and prepare updates to documents and structured items.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Tana OAuth 授权；受账号权限与服务配额限制。 本连接使用 home.tana.inc 上的 Tana 托管 MCP。写入通常生成待审核提案，待审提案不代表编辑已生效。

Connect in Ghast and complete Tana OAuth in the provider browser page. Account permissions and service quotas apply. This connection uses the Tana hosted MCP at home.tana.inc. Writes normally create proposals for review; pending proposals are not completed edits.

- MCP: `https://home.tana.inc/mcp`
- [官方文档 / Provider documentation](https://tana.inc/learn/features/mcp)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
