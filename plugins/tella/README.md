# Tella for Ghast

## 简介 / Overview

使用 Tella 搜索视频、编辑片段、整理播放列表并导出成片。

Find videos, edit clips, organize playlists and export finished videos with Tella.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Tella OAuth 授权；受账号权限与服务配额限制。

Connect in Ghast and complete Tella OAuth in the provider browser page. Account permissions and service quotas apply.

- MCP: `https://api.tella.com/mcp`
- [官方文档 / Provider documentation](https://www.tella.com/docs/mcp-server)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
