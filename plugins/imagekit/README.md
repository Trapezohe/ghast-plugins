# ImageKit for Ghast

## 简介 / Overview

管理媒体素材，构建图片与视频变换。

Manage media assets and build image and video transformations.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 ImageKit OAuth 授权；受账号权限与服务配额限制。 当前为公开预览。DevTools 无需账号；API 连接通过 ImageKit OAuth，在服务商页面输入限定权限的私有 API Key。

Connect in Ghast and complete ImageKit OAuth in the provider browser page. Account permissions and service quotas apply. Public preview. The DevTools connection is public; the API connection opens ImageKit OAuth, where a scoped private API key is entered on the provider page.

- MCP: `https://api-mcp.imagekit.io/mcp`
- MCP: `https://devtools-mcp.imagekit.io/mcp`
- [官方文档 / Provider documentation](https://imagekit.io/docs/build-with-ai)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
