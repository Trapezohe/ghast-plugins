# Redpanda for Ghast

## 简介 / Overview

检索 Redpanda 官方文档和 API 参考，了解流式集群、Kafka 兼容性、Connect 数据管道与运维排障。

Search Redpanda’s official documentation and API references for streaming clusters, Kafka compatibility, Connect pipelines and operational troubleshooting.

## 连接 / Connection

公开 MCP 服务，无需账号或 API Key。 实际 MCP 工具发现返回五个工具，API 参考搜索返回相关文档。托管工具可能要求提供不含敏感信息的用途说明以供分析。

Public MCP service; no account or API key required. Actual MCP discovery returned five tools and an API-reference search returned relevant documentation. The hosted tools may request non-sensitive context for analytics.

- MCP: `https://docs.redpanda.com/mcp`
- [官方文档 / Provider documentation](https://docs.redpanda.com/home/how-to-use-these-docs/)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
