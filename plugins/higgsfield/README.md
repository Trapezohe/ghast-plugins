# Higgsfield for Ghast

## 简介 / Overview

连接 Higgsfield 官方 MCP，使用账号积分创建图像、视频、角色与音频。

Connect to Higgsfield’s official MCP for image, video, character and audio creation using your account credits.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Higgsfield OAuth 授权；受账号权限与服务配额限制。 通过 OAuth 登录自己的 Higgsfield 账号。MCP 生成会消耗账号积分，网页专享的免费或无限权益不代表自动化生成免费。已验证到服务商 PKCE 授权跳转，未完成账号授权、余额查询或付费生成。

Connect in Ghast and complete Higgsfield OAuth in the provider browser page. Account permissions and service quotas apply. Sign in with your own Higgsfield account through OAuth. MCP generation consumes account credits; web-only free or unlimited entitlements do not imply free automated generations. Verification reached the provider PKCE redirect before consent. Account access, balance checks and paid generation were not tested.

- MCP: `https://mcp.higgsfield.ai/mcp`
- [官方文档 / Provider documentation](https://higgsfield.ai/creator-hub/help-center/integrations/what-is-higgsfield-mcp)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
