# CryptoRank for Ghast

## 简介 / Overview

通过 CryptoRank 官方 MCP（Beta）研究加密项目融资、投资机构、代币解锁与团队。

Research crypto funding rounds, investors, token unlocks and project teams through CryptoRank’s official MCP (Beta).

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 CryptoRank OAuth 授权；受账号权限与服务配额限制。 服务为 Beta，需要具有 MCP 访问权限的 CryptoRank API 套餐。数据覆盖与配额取决于当前套餐，请以服务商最新套餐权益为准。

Connect in Ghast and complete CryptoRank OAuth in the provider browser page. Account permissions and service quotas apply. The service is Beta and requires a CryptoRank API plan with MCP access. Dataset coverage and quotas follow your current plan; check the provider pricing page for current entitlements.

- MCP: `https://api.cryptorank.io/mcp`
- [官方文档 / Provider documentation](https://cryptorank.io/insights/analytics/how-to-use-CryptoRank-MCP-server)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
