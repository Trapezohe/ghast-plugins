# Lucid for Ghast

## 简介 / Overview

创建和检索 Lucid 图表，梳理业务流程与团队协作。

Create and explore Lucid diagrams for processes and collaboration.

## 连接 / Connection

在 Ghast 中连接，通过服务商网页完成 Lucid OAuth 授权；受账号权限与服务配额限制。 团队或企业管理员可能需要先开启 MCP 访问。

Connect in Ghast and complete Lucid OAuth in the provider browser page. Account permissions and service quotas apply. Team or Enterprise administrators may need to enable MCP access.

- MCP: `https://mcp.lucid.app/mcp`
- [官方文档 / Provider documentation](https://help.lucid.co/hc/en-us/articles/42578801807508-Integrate-Lucid-with-AI-tools-using-the-Lucid-MCP-server)

安装后在插件详情连接服务。安装成功不代表账号授权或业务调用成功。

Install the plugin, then connect in its detail page. Installation does not prove account authorization or business task execution.

本包由 Ghast 独立编写，使用服务商公开 MCP，不包含 Codex 私有连接器或账号凭据。

Independently authored for Ghast using public provider MCP services, without Codex private connectors or credentials.
